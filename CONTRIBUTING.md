# Contributing

Please open an issue describing the behavior you want to change. For a bug,
include the ROM revision, emulator/hardware model, bridge configuration,
reproduction steps, and relevant logs with credentials or signed URLs removed.

Use English for public issue and pull request descriptions when possible.
The default UI and primary documentation are English; the touchscreen keyboard
also supports Russian input. Keep the language links in README.md and
README.ru.md working when updating documentation.

Run the server/native checks and build the ROM before submitting code;
commands are in [README.md](README.md#development). Device-specific changes
should identify what was tested in melonDS and what was tested on physical DS
hardware. Generated font/icon headers must remain reproducible from bundled
sources and their generator scripts.

Contributions are provided under this project's GPL-3.0-only license.
Keep third-party notices with any new assets.
