# Локальная ручная проверка

Сначала установить зависимости, собрать ROM и поместить melonDS в `tools/melonds`. См. [English setup](../README.md#quick-start) / [русскую инструкцию](../README.ru.md). Существующие назначения клавиш эмулятора сохраняются.

## Запуск

Двойной щелчок в корне проекта:

- **Start SoundCloud.cmd** — сервер SoundCloud и melonDS с поиском треков. Forss — Flickermood остаётся треком по умолчанию.
- **Start Test Tone.cmd** — независимая проверка сети/звука тестовым тоном 440 Гц на десять минут; поиск в этом режиме возвращает тестовый тон.
- **Stop Local Server.cmd** — корректно остановить сервер. Окно melonDS закрывается отдельно.

Чтобы загрузить пересобранный ROM, закрыть окно melonDS и повторно запустить Start SoundCloud.cmd. Если окно уже открыто, второй экземпляр не создаётся и ROM автоматически не перезагружается. Переключение режима перезапускает сервер; после него остановить старый трек и запустить новый. Незавершённый запрос SoundCloud при остановке может потребовать несколько секунд ожидания.

## Поиск

1. На экране подключения выбрать **melonAP** мышью или крестовиной + DS A.
2. Нажать строку поиска или DS Y. На экранной клавиатуре набрать трек/исполнителя, нажать **Search**. Начальный экран показывает приглашение к поиску без кнопок категорий.
3. Нажать результат, чтобы воспроизвести его. Крестовина вверх/вниз выбирает строку, DS A запускает.
4. Крестовина влево/вправо или кнопки `< Prev` и `Next >` листают страницы. На странице максимум четыре результата, все видны одновременно.
5. Продолжать поиск во время музыки. На Player доступны play/pause, −5s/+5s, сенсорный прогресс и Previous/Next. Громкость меняют только плечевые L/R. DS X переключает вкладки, шестерёнка открывает настройки сервера и Wi-Fi.

## Управление

Подписи A/B/X/Y в интерфейсе обозначают **кнопки Nintendo DS**, а не обязательно одноимённые клавиши ПК. Привязки задаются в **Config → Input and hotkeys**. Используйте собственную раскладку; репозиторий не содержит пользовательский конфиг melonDS. Щёлкнуть по окну для ввода с клавиатуры.

| Кнопка DS | Search | Player | Экранная клавиатура |
|---|---|---|---|
| A | Запустить выделенный трек | Play/pause | Выбрать клавишу |
| B | Stop | Stop | Отменить редактирование |
| X | Переключить вкладку | Переключить вкладку | Удалить символ |
| Y | Ввод запроса | Ввод запроса | Выполнить поиск |
| Крестовина | Выделение и страницы | Влево/вправо ±5s, вверх/вниз треки | Навигация по клавишам |
| L/R | Громкость | Громкость | Громкость |
| SELECT | Показать/скрыть Buffer/Gaps | Показать/скрыть Buffer/Gaps | — |
| START | Выйти из приложения | Выйти из приложения | Выйти из приложения |

Мышь заменяет стилус: клавиатура, вкладки, результаты, транспорт и прогресс работают сенсорно. На Player потянуть полосу над play/pause: время показывается сразу, seek выполняется после отпускания. Пауза сохраняется. Близкие переходы используют буфер/текущее соединение, далёкие требуют повторной буферизации. Кнопка EN/RU меняет язык ввода, интерфейс английский. Шестерёнка справа сверху открывает Settings: адрес сервера, Wi-Fi и Test connection. Обложка и акцентный цвет загружаются автоматически; отсутствие картинки не мешает звуку.

## Что проверять

- Поиск разных исполнителей, пустой результат, страницы вперёд/назад.
- Кириллица в запросе, названии и исполнителе; удаление символа в RU-раскладке.
- Запуск найденного трека, пауза, продолжение, stop/restart, переключение на другой результат.
- Поиск во время музыки: время продолжает идти, звук не прерывается.
- Громкость плечевыми L/R на разных экранах; центрирование play/pause и надписей.
- Settings: редактор IPv4:port, пресет Emulator, Test connection и возврат к музыке.
- Загрузка разных обложек, общая акцентная тема и визуализация на фоне верхнего экрана. На паузе столбцы затихают.
- Settings: переключение Emulator/Console и независимое редактирование адресов.
- Естественное завершение трека: автоматический запуск рекомендации. Stop и seek точно в конец не должны запускать следующий трек.
- −5s/+5s во время игры и паузы; переходы к началу/концу; несколько быстрых нажатий.
- Перетаскивание полосы прогресса с предпросмотром, переход после отпускания и дальнейшее правильное время.
- SELECT показывает буфер и Gaps; счётчик пропусков не должен расти на стабильной сети.
- Десять минут тестового тона и полный SoundCloud-трек. Физическая DS Fat пока требует отдельной проверки.

Первое обращение к SoundCloud может занимать до 35 секунд. При временной ошибке повторить запуск; во время освобождения старого потока запрос повторяется автоматически. Если звука нет, увеличить громкость DS кнопкой R и проверить громкость самого melonDS.

## Локальная сеть

Сервер слушает только **127.0.0.1:8765**; ROM обращается к **10.64.0.1:8765** — шлюзу indirect networking melonDS. Ethernet/VPN и входящий firewall менять не нужно. Встроенные BIOS/firmware, DS mode, direct boot и актуальная официальная nightly уже настроены.

Логи: `tools/.cache/local/server.log`, `server.err.log`, `emulator.log`, `emulator.err.log`. Состояние: <http://127.0.0.1:8765/healthz>. Описание реализации и API: [SEARCH_UI.md](SEARCH_UI.md).

Для настоящей DS Fat указать LAN-адрес ПК или IPv4 VPS в Settings. На flashcart с доступной FAT адрес сохраняется в `/soundcloud-ds.cfg`; в текущем melonDS без SD — на сессию. [Подробности настроек и обложек](UI_ARTWORK_SETTINGS.md).
