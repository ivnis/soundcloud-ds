# Проверки от 2026-10-25

Среда: Windows, Python 3.13, BlocksDS 1.24.0, Wonderful ARM GCC 16.2.0, локальный FFmpeg из imageio-ffmpeg 0.6.0.

| Проверка | Результат |
|---|---|
| `tools/check.ps1` | 17 серверных тестов прошли; C++-тесты HTTP и кольцевого буфера прошли |
| Нативная ARM-сборка | `client/soundcloud_ds.nds`, 256 512 байт |
| HTTP/1.0 | Реальный PCM, без chunked; отключение освобождает поток |

Полные потоки читались с максимальной скоростью, без записи музыки на диск: тестовый тон за 0,12 с, трек SoundCloud за 12,24 с. Эти результаты подтверждают серверный тракт, формат и завершение потока; они не измеряют realtime-производительность DS.

При живой проверке обнаружены и учтены `MONETIZE` для доступных полных треков, CDN `playback.media-streaming.soundcloud.cloud` и устаревшие альтернативные transcodings. Отдельные обращения к SoundCloud давали таймаут/ошибку источника; добавлены общий бюджет lookup, ограничение старта FFmpeg и возможность повторного запроса. Неофициальный upstream остаётся внешней зависимостью.

Предупреждения инструментов: установленный Starlette сообщает о будущем переходе TestClient с httpx на httpx2; ARM linker предупреждает об отсутствии GNU-stack note в поставляемом SDK `crtn.o`. Тесты и сборка завершились успешно.

- Для настоящей DS указать реальный IP сервера в `client/include/config.local.h` и пересобрать ROM. Текущая локальная сборка использует шлюз melonDS `10.64.0.1:8765`.
- В melonDS закончить ручную проверку кнопок, сенсорных зон и десяти минут воспроизведения без underrun.
- Повторить на DS Fat через flashcart и совместимую WiFi-точку; проверить паузу, восстановление буфера и обрыв сети.
- Развернуть Docker Compose на VPS и повторить проверку из сети консоли. Контейнер здесь не запускался: Docker и доступ к VPS не предоставлены.

## Перемотка и бюджет обложек

- C++-тесты проверили историю/предзагрузку, переходы через границу кольца, локальный seek и пропуск входящего аудио вперёд, ограничение ±5s началом/концом, координаты progress slider и HTTP-заголовок X-Audio-Start-Ms.

- Обновлённый ROM загружен в melonDS, сервер возвращён в режим SoundCloud. Текущая ручная проверка интерфейса/перетаскивания оставлена пользователю, назначения клавиш сохранены. На физической DS Fat seek пока не проверялся.

## Сканирование Wi-Fi и диагностические попытки

Добавлены кэшированный снимок AP, проверка ошибок чтения, сохранение выделения по BSSID и приоритет совместимых именованных сетей. Пустые SSID обозначаются Hidden с окончанием BSSID; неизвестное имя не угадывается. Интерфейс показывает диапазон/число сетей, прокрутку и Rescan/DS B. В melonDS проверены отображение melonAP в новом списке и состояние Online после подключения.

При выборе несовместимой сети добавлен отдельный экран предупреждения с Try anyway/Cancel. После явного подтверждения передаётся обычный запрос DSWifi, для WPA/WPA2 доступен ввод пароля. Это не добавляет DS Fat аппаратную поддержку WPA/WPA2, библиотека может отказать до ассоциации. 65 серверных тестов и native C++ проверки прошли; тесты дополнены форматированием скрытых SSID, ограничениями буфера и управляющими символами. ARM-сборка успешна, превью предупреждения и списка просмотрены. Подключение настоящей DS Fat к POCO M7 не проверено; диапазон/legacy-совместимость точки требует проверки на телефоне.
