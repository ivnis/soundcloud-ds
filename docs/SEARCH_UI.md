# Search & player UI

Основной язык интерфейса — **английский**. Язык клавиатуры переключается между EN и RU, отдельно есть цифры и знаки. Шрифт Gohufont отображает латиницу и кириллицу в запросах, названиях и исполнителях; неподдерживаемые символы, например большинство emoji, заменяются знаком `?`.

## Два экрана

Верхний экран показывает обложку, текущий трек, исполнителя, состояние и громкость. Время и единственная полоса прогресса находятся на нижнем **Player**. На нижнем экране также есть **Search** и шестерёнка **Settings** для выбора сервера и Wi-Fi. [Настройки и оформление](UI_ARTWORK_SETTINGS.md).

**Search:** нажать строку поиска или DS Y, набрать запрос стилусом/мышью либо выбрать клавиши крестовиной и DS A. Кнопка Search или DS Y отправляет запрос. DS X удаляет символ, DS B отменяет редактирование. Введённый запрос сохраняется при переходах между экранами.

В результатах видны название, исполнитель и длительность. Нажатие по строке запускает трек; крестовина вверх/вниз выбирает строку, DS A запускает выбранную. Страница загружает максимум четыре результата, все они видны одновременно. Крестовина влево/вправо или кнопки Prev/Next переключают страницы. Сервер фильтрует preview/заблокированные записи, поэтому страница иногда содержит меньше четырёх строк.

Поиск имеет отдельное неблокирующее HTTP-соединение и не останавливает музыку. Нижняя мини-панель позволяет поставить текущий трек на паузу или остановить его, оставаясь в поиске. При ошибке поиска старые результаты не запускаются случайным нажатием A: A повторяет неудавшийся запрос.

**Player:** большая кнопка play/pause, −5s/+5s, интерактивная полоса прогресса и Previous/Next. DS A — play/pause, B — stop, плечевые L/R — громкость, крестовина влево/вправо — ±5 секунд, вверх/вниз — предыдущий/следующий трек. Сенсорный регулятор громкости убран. DS X переключает вкладки, DS SELECT — технические показатели буфера. При перетаскивании прогресса позиция показывается в предпросмотре; отпускание выполняет seek с сохранением паузы. [Перемотка](SEEK_AND_ARTWORK.md).

## API

`GET /v1/search?q=lofi&offset=0&limit=4`

```json
{
  "tracks": [
    {"id": "49438146", "title": "Lux Aeterna", "artist": "Forss", "duration_ms": 370201}
  ],
  "offset": 0,
  "next_offset": 4,
  "has_more": true
}
```

`q` после удаления краевых пробелов должен содержать 1–80 символов, `limit` — 1–4, `offset` — 0–5000. Клиентская клавиатура ограничивает запрос 48 Unicode-символами. Ответ — JSON UTF-8; клиент разбирает его в фиксированном буфере 16 КБ с проверкой размеров, IDs и Unicode escape sequences.

`GET /v1/audio?track_id=49438146&start_ms=30000` выбирает трек и начальную позицию в миллисекундах; `GET /v1/track?track_id=49438146` возвращает его метаданные. Допустим только числовой ID до 20 цифр; произвольные URL от клиента не принимаются. Без `track_id` сохранён запуск трека из серверной конфигурации, без `start_ms` — с начала. В тестовом режиме поиск возвращает локальный тестовый тон с ID `0`.

Перед воспроизведением сервер получает метаданные и подписанную ссылку; недавно использованные источники кешируются на 120 секунд для ускорения seek/restart. Во время подготовки источника запросы поиска могут временно получать 503; клиент повторяет их с задержкой. Повторный запуск после остановки также ожидает освобождения старого потока, а B отменяет ожидание. Отключение клиента во время подготовки не создаёт ненужный FFmpeg-процесс; уже выполняющийся вызов SoundCloud завершается в фоне с удержанием lookup-lock.

## Графика и память

Интерфейс рисуется кодом в двух 16-bit bitmap-буферах 256×192 и переносится в VRAM после VBlank. Нет повторной очистки текстовой консоли во время вывода. Аудиобуфер, сетевые автоматы и обработка ввода продолжают работать в основном цикле. Wave-иконка — декоративная анимация, не анализатор аудиосигнала.

Данные шрифта генерируются `python tools/generate_font.py` из включённого BDF; генерация не нужна для обычной сборки. Источник: [Gohufont](https://github.com/hchargois/gohufont), автор Hugo Chargois, лицензия в `client/assets/COPYING-LICENSE`.
